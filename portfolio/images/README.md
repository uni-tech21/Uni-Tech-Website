# Portfolio screenshots

Put new website screenshots in this folder, for example `new-client.webp`.

Then add the project to `../projects.json` with:

```json
{
  "name": "New client",
  "url": "https://example.com/",
  "image": "images/new-client.webp"
}
```

Use simple filenames with letters, numbers and hyphens. PNG, JPG, WebP and AVIF work well. A screenshot around 1800 pixels wide is recommended.

See `../README.md` for adding projects, changing their order and optional descriptions.
